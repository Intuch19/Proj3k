Import Stock from Excel File

Attach an .xlsx file with Color No / Yards / Total columns (same format as MILTON STOCK and THAI SILK) — the system reads it and adds to stock automatically. A value written as "17x30" is interpreted as 17 rolls of 30 yards each, combined into one entry.

Add Stock Manually

Choose a fabric type, then add Color (COLOR #) as new rows and Yards (YDS) as columns in each row — totals are calculated automatically. Each yard entry is stored individually and shown alongside the running total in the Real-time table above.
